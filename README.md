# Victoria E. Penny — Professional Portfolio

A static professional portfolio built for GitHub Pages.

## Publish with GitHub Pages

1. Upload all files and folders in this project to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose **main** and **/(root)**, then select **Save**.
5. GitHub will display the published address after deployment finishes.

## Files

- `index.html` — site content
- `styles.css` — visual design and responsive layout
- `script.js` — navigation, date, and subtle reveal animation
- `assets/` — headshot and résumé
